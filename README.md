# 🏥 말랑병원

동물 친구들을 돌보는 귀여운 병원 타이쿤 게임이에요. 원장님이 되어 환자를 접수하고, 맞는 진료과로 안내하고, 병원을 키워 보세요!

**▶ 플레이:** https://changon-lee.github.io/mallang-hospital/

## 특징
- 단일 `index.html` (HTML + CSS + 바닐라 JS), 외부 라이브러리·이미지 없음
- PC 마우스 / 모바일 터치 지원, 자동 저장(localStorage)
- 화면 크기에 맞춰 병원 맵이 꽉 차게 자동으로 커지고 작아져요 (폰 세로 · PC 모두, 스크롤 없음)
- 일시정지 · 1x · 2x · 4x 배속

## 게임 방법
1. **접수** — 입구의 환자를 톡!
2. **안내** — 환자 톡 → 증상에 맞는 진료과 톡
3. **치료 분기** — 진료 후 머리 위 아이콘을 보고 💊 약국 / 💉 주사실 / 🛏️ 입원실 / ⚕️ 수술실로
4. **수납** — 수납 창구에서 톡! 빨리 받을수록 팁, 실수 없이 이어 가면 콤보

## 특별한 환자
- 🚨 **응급 환자** — 제한 시간(38초, 날이 갈수록 28초까지 줄어요) 안에 진료를 시작해야 해요
- 🩺 **복합 증상** — 진료과 두 곳을 차례로 들러야 해요
- 🕶️ **진상 환자** — 소란을 피우면 톡톡 눌러 달래 주세요
- 👑 **VIP** · ❓ **원인 불명** (검사실 또는 50% 도박)

## 성장
진료과 해금(내과 → 정형외과 → 안과 → 치과 → 피부과 → 산부인과 → 이비인후과 → 신경과), 방 업그레이드, 인테리어, 직원 고용,
병원 등급(동네의원 → 병원 → 종합병원 → 대학병원)에 따라 병원 맵이 넓어져요.

- 🩺 **의사 여러 명** — 진료과마다 의사를 더 뽑으면 진료 의자가 늘어나 동시에 진료해요
- 💳 **수납 간호사** — 병원 등급부터, 수납을 자동으로 처리해요
- 🧭 **약국 안내 간호사** (종합병원부터) · 🩹 **주사 안내 간호사** (대학병원부터) — 진료 끝난 환자를 알아서 보내요
- ⚡ 간호사는 속도가 느리면 환자가 밀려요(📥) — 밀린 환자는 원장님이 직접!
- 💌 **지원자** — 실력 좋은 지원자도 와요. 대신 능력이 좋을수록 일급이 훨씬 비싸요
- 👥 **직원 명부** — 직원 목록을 보고 이름을 마음대로 바꿀 수 있어요
- 📚 **직원 연수** — 일하면서 크는 건 아주 천천히, 빨리 키우려면 연수를 보내요
- 📣 **홍보** — 종합병원부터 돈을 들여 환자를 더 불러요
- 🛏️ **입원실** — 침대 기본 2개, 업그레이드마다 2개씩 (최대 8개)
- 🧩 **방 배치** — 영업 준비 화면에서 크기가 같은 방끼리 자리를 바꿀 수 있어요
- ⭐ **평판 보너스** — ⭐3.0 진료비 +10% · ⭐4.0 +25% · ⭐4.5 +40% · ⭐4.8 +60%. 높을수록 오르기 어렵고, 콤보가 끊기면 조금 떨어져요
- ⚕️ **수술실** — 대학병원에서 열리는 큰 수입원

## 개발
테스트: `py -m pip install -r requirements-dev.txt`, `py -m playwright install chromium`, `py -m pytest tests -q`

## 실행
`index.html`을 브라우저로 열면 바로 플레이할 수 있어요.
