# 말랑병원 후반 콘텐츠 설계 — 신관 · 장비 · 기부/봉사 · 연구 · 트로피

## 왜
대학병원까지 다 열고 나면 돈을 쓸 곳이 없다 (일회성 구매만 있고, 남는 지출은 일급·홍보뿐).
목표: **대학병원 이후에도 10~20일 더 즐길 거리**를 주는 것. 사용자가 "잘 샀다"고 느끼는 순간은
**새로 산 것 덕분에 기존보다 확실히 나아졌을 때** — 손님이 빨리 빠지고, 하루 수입이 오르고, 평판이 덜 깎이는 게 **눈에 보일 때**다.

## 목표 / 비목표 / 실패 조건
- 목표
  - 큰 장기 목표(신관 5단계)와 계속 쓰는 지출(장비·기부·연구)을 함께 제공한다.
  - 모든 구매는 효과를 숫자로 보여준다 (상점에 지금 → 다음, 결산에 보너스 줄).
  - 신관은 **새 방과 새 환자**를 들여온다 (사용자 선택).
- 비목표
  - 헤드헌터, 2호점/재개원(프레스티지), 인테리어 테마 — 이번엔 안 함.
  - 별도 층/탭 화면 — 안 함.
  - 신관 전담 직원 고용·관리 — 안 함.
- 실패 조건 (동작해도 실패)
  - 본관 화면이 지금보다 정신없어진다 (사용자: 후반엔 과가 많아 이미 정신없음).
  - 돈을 썼는데 체감 효과가 없다.
  - 기존 v2 세이브가 깨진다 (세이브 키·버전 유지, 새 필드는 기본값으로 채움).

## 제약
- 단일 파일 `index.html` (바닐라 JS, 전역 `S` 저장 / `G` 하루 상태). 외부 라이브러리 없음.
- 테스트: `tests/` pytest + Playwright (conftest의 `boot`, `js`, `tick`, `spawn_patient`). 기존 113개 통과 유지.
- 저장: `S.v === 2` 유지. `startGame(Object.assign(newState(), s))` 얕은 병합이므로 새 최상위 필드는 `newState()`에 기본값을 둔다.
  중첩 객체 필드를 추가할 땐 로드 시 기본값 보정이 필요하다 (예: `S.eq = Object.assign({}, S.eq)`).
- 기준 경제: 대학병원·전 과 오픈·장비 만렙 직전·봇 완벽 플레이 기준 하루 순이익 ≈ 1.6만. 실제 플레이는 0.8~1.2만으로 본다.
  후반 콘텐츠 총 지출 규모 ≈ 25~35만 (10~20일 분량)로 맞춘다.

## 1. 🏗️ 신관 (사용자 결정 사항 포함)

### 사용자가 정한 것
- 탭/층 전환 없음. 한 화면에 다 펼치지도 않음 → **본관 지도에 "신관" 카드 하나**, 그 안에 작은 칸 5개.
- 칸마다 전담 직원이 같이 들어오고 **알아서 굴러간다**. 고용 관리 없음.
- 새 유형 환자는 **알아서 신관으로 간다** (원장님이 직접 할 일은 거의 없음).
- **돈을 더 내면 더 빨리 지어진다.**

### 공사
- 5단계, 순서 고정. 각 단계 = 신관 칸 하나.

| 단계 | 칸 | 기본 공사비 | 기본 공사 기간 | 하루 운영비 |
|---|---|---|---|---|
| 1 | 👧 소아과 | 8,000 | 3일 | 200 |
| 2 | 🚑 응급실 | 14,000 | 3일 | 300 |
| 3 | 🦿 재활치료실 | 20,000 | 4일 | 350 |
| 4 | 💎 VIP 특실 | 28,000 | 4일 | 450 |
| 5 | 🚁 헬기장 | 38,000 | 5일 | 600 |

- 착공: 영업 준비 화면에서 기본 공사비를 내면 시작. 한 번에 한 단계만 공사.
- **빨리 짓기**: 공사 중인 동안 영업 준비 때 "하루 단축" 버튼 — 남은 날 1일당 `ceil(기본 공사비 × 0.35)`. 여러 번 눌러도 됨. 0일이 되면 **즉시 완공**.
- 남은 날은 하루 결산(`endDay`) 때 1씩 줄고, 0이 되면 다음 날 아침에 완공 연출(축하 모달).
- 운영비는 완공된 칸마다 매일 결산에서 빠지고, 결산에 "🏥 신관 운영비" 줄로 표시.

### 지도
- 대학병원 레이아웃(넓은 화면·좁은 화면 모두)에 `annex` 영역 추가. 넓은 화면은 오른쪽 세로 3칸, 좁은 화면은 맨 아래 가로 1줄 정도를 제안 — 정확한 배치는 빌더 판단.
  기존 방 크기가 크게 줄면 안 됨 (`fitMap`의 pz가 지금 대비 눈에 띄게 줄지 않게, 1440x900·390x744에서 확인).
- 대학병원이 되면 공사 전이어도 신관 카드는 보이고, 미완공 칸은 회색 🏗️ (공사 중이면 남은 일수 표시).
- 신관 카드 톡 → 신관 상세 창 (단계별 정보, 착공/하루 단축 버튼, 각 칸 정원·처리 속도·오늘 수입). 영업 중엔 정보만(일시정지 같은 모달 처리), 착공/단축은 영업 준비 때만.
- 레이아웃 편집(🧩 배치): 신관 카드는 모양이 고유해 교환 대상이 없어도 됨. 저장된 대학병원 커스텀 배치는 방 이름 집합이 바뀌므로 기본 배치로 돌아가는데, 이는 허용.

### 신관 칸 동작 (공통)
- 칸마다 정원(기본 1명, 연구로 +1), 처리 시간, 진료비가 있다.
- 신관으로 가는 환자는 본관에서 신관 카드까지 걸어간 뒤 **신관 카드 안으로 사라진다** (본관 의자를 차지하지 않음).
  신관 안에서는 환자 스프라이트 대신 칸별 **진행 막대 + 대기 인원 수**를 보여준다.
- 대기 인원이 정원보다 2명 이상 많으면 그 칸에 📥 표시 (기존 백로그 표시와 같은 모양). 신관 대기 중에도 하트는 **천천히(×0.5)** 줄고, 다 닳으면 기존처럼 화내고 떠난다.
- 처리가 끝나면 환자는 본관 수납 줄로 돌아온다 (수납 간호사가 있으면 자동 수납). 헬기·특실은 예외(아래).
- 신관에서 번 돈은 `G.stats.annexIncome`에 따로 모아 결산에 "🏥 신관 수입" 줄로 보여준다 (평판 보너스 등은 기존 규칙대로 적용).
- 원장님 수동 조작: 필요 없음. 단, 신관으로 가야 할 환자를 원장님이 신관 카드로 직접 보내면 자동 이동 대기(약 2초)를 건너뛴다.

### 칸별 새 환자
1. **👧 소아과**
   - 완공 후 일반 환자 중 일정 비율(약 15%)이 아이 환자: 말풍선 🧸, 동물 앞에 작은 표시(예: 🎀).
   - 접수(간호사/원장님) 후 약 2초 뒤 자동으로 신관 소아과로.
   - 하트가 1.3배 빨리 줄고, 하트가 30% 아래로 떨어지면 울음(😭) — 울고 있는 아이가 있으면 주변 대기 환자 하트가 진상 소란처럼 조금 더 빨리 줄어든다(×1.2).
   - 처리 6초, 진료비 70 + 약국 없이 바로 수납.
2. **🚑 응급실**
   - 완공 후 하루 응급 환자 +2 (구급차 연출). 이 환자들은 접수 없이 **자동으로 응급실로** 간다.
   - 기존 응급 환자(진료과로 보내야 하던)도 원장님이 신관 카드로 보내면 응급실에서 바로 처치 시작(구조 성공 처리).
   - 처리 8초, 진료비는 기존 응급 보너스와 같은 규칙 + 기본 90.
3. **🦿 재활치료실**
   - 완공 후 정형외과·신경과·수술실을 마친 환자의 다음 목적지에 🦿가 추가(가중치 약 2).
   - 🦿 목적지 환자는 자동으로 신관 재활치료실로. 처리 7초, 진료비 60.
4. **💎 VIP 특실**
   - 완공 후 VIP 환자가 진료를 마치면 입원실 대신 특실로 갈 수 있다(입원 판정이 나온 VIP는 항상 특실, 그 외 VIP도 30%).
   - 특실 정원 기본 2. 입원실처럼 하루가 끝날 때 퇴원하며 `(입원 퇴원비) × 2`를 낸다. 결산 "🏥 신관 수입"에 포함.
5. **🚁 헬기장**
   - 완공 후 하루 1~2회 헬기 환자 등장(토스트 + 효과음). 신관 헬기장으로 바로 도착(본관을 거치지 않음).
   - 처리 10초, 끝나면 자동 수납: `400 + 일수×10` × 평판 배율. 정원 초과 시 대기, 대기 중 하트가 다 닳으면 평판 -6.

## 2. ⚙️ 장비 (진료과·방별 레벨)
- 대상: 열린 진료과 8개 + 검사실·주사실·약국·수술실 + (완공된) 신관 칸들.
- 레벨 0~10. 등급별 최대 레벨 제한(위 표).
- 효과(레벨 L):
  - 진료과: 진료 시간 ÷ (1 + 0.06L), 그 과 진료비 × (1 + 0.03L).
  - 검사·주사·약국·수술·신관 칸: 처리 시간 ÷ (1 + 0.06L). 수술·신관은 비용도 × (1 + 0.03L).
  - 기존 공통 업그레이드 `UPS.clinic`(진료실 장비)은 그대로 두고 곱한다. 이름 충돌을 피하려 `UPS.clinic`은 "진료실 기본 장비"로 표기 변경을 권장.
- 가격: `round(base × 1.45^L / 10) × 10`, base = 250 + 진료과 순서×40 (방은 300, 신관 칸은 600). L9→10이 약 9천~1.6만.
- 상점에 "⚙️ 장비" 탭 신설. 카드마다 Lv, 지금 → 다음 수치(예: "진료 5.2초 → 4.9초 · 진료비 💰45 → 💰46"), 가격.
- 검사실은 레벨 구간별 이름으로 재미를 준다: Lv1~3 X-ray, Lv4~6 CT, Lv7~10 MRI (진료과는 ★ 표기면 충분).
- 방 카드 머리에 장비 레벨이 1 이상이면 작게 "Lv3" 표시 — 빌더 판단(화면 맞춤에 영향 없게).

## 3. 🤝 기부 · 봉사 진료
- 영업 준비 화면에 홍보 박스처럼 "🤝 나눔" 박스.
- **기부** (하루 1번): 세 가지
  - 💝 작은 기부: `500 + 일수×20` → 평판 +2
  - 💐 큰 기부: `1500 + 일수×50` → 평판 +5
  - 🏛️ 장학 재단: `4000 + 일수×120` → 평판 +10
  - 평판 상승은 `addRep`을 거치므로 높은 평판에선 자연히 효율이 떨어진다.
  - 누적 기부액 `S.donated` 저장(트로피용).
- **봉사 진료의 날**: 영업 준비 때 선택, 3일에 한 번(쿨다운).
  - 그날 진료비·팁·특별 보너스 0원 (일급·운영비는 그대로 나감 → 이것 자체가 지출).
  - 환자 1.3배 더 옴. 콤보 끊김 평판 감점 절반. 수납 1명당 평판 +1.0 (평소 +0.45). 하루 끝에 평판 +5.
  - HUD나 지도 위에 "🤝 봉사 진료의 날" 표시. 결산에 "봉사 진료로 평판 +x" 줄.
  - 홍보와 같은 날 동시 사용 가능.

## 4. 🧪 의학 연구
- 연구실 창: 갈래 3개 × 4단계, 갈래 안에서는 순서대로. 한 번에 하나만 연구.
- 연구 시작 = 영업 준비 때 비용 지불. 남은 기간은 결산 때 1일씩 줄고, 끝나면 다음 날 아침 "연구 완료!" 토스트/모달.
- 저장: `S.res = { done:{id:true}, cur:null | {id, left} }`.

| 갈래 | 단계 | 이름 | 비용 | 기간 | 효과 |
|---|---|---|---|---|---|
| 진료 | 1 | 신속 진단 | 3,000 | 1일 | 모든 진료 시간 -10% |
| 진료 | 2 | 정밀 검사 | 5,000 | 2일 | 검사실 처리 -30%, 검사 없이 보낸 ❓ 성공률 50→65% |
| 진료 | 3 | 신약 개발 | 8,000 | 2일 | 약국 처리 -25% |
| 진료 | 4 | 첨단 수술 | 14,000 | 3일 | 수술 처리 -30%, 수술비 +30% |
| 운영 | 1 | 친절 교육 | 3,000 | 1일 | 환자 하트 감소 -8% |
| 운영 | 2 | 스마트 접수 | 6,000 | 2일 | 간호사 계열 처리 간격(`navInt`) -20% |
| 운영 | 3 | 피로 관리 | 9,000 | 2일 | 직원 피로 쌓임 -25% |
| 운영 | 4 | 의료 경영 | 15,000 | 3일 | 모든 진료비 +10% |
| 신관 | 1 | 놀이 치료 | 6,000 | 2일 | 소아과 정원 +1, 아이 울음 시작 하트 30→20% |
| 신관 | 2 | 응급 프로토콜 | 9,000 | 2일 | 응급 제한 시간 +8초, 응급실 처리 -30% |
| 신관 | 3 | 재활 로봇 | 12,000 | 3일 | 재활치료실 정원 +1 |
| 신관 | 4 | VIP 컨시어지 | 16,000 | 3일 | 특실 정원 +1, 특실 수입 +30% |

- 신관 갈래 단계 n은 신관 n단계(해당 칸) 완공 후에 연구 가능. 헬기장은 연구 대상 없음.
- 창에는 각 연구의 효과를 지금 수치 → 연구 후 수치로 보여준다.

## 5. 🏆 트로피 홀
- 업적을 달성하면 트로피 1개 + **진료비 +1% 영구 보너스**(트로피 수만큼 누적, 최대 약 +28%).
  - 적용 위치: `pay()`와 결산 퇴원비/자동 수납에서 평판 배율과 곱한다. 결산에 "🏆 트로피 보너스 (포함)" 줄.

## UI 정리
- 영업 준비 화면에 버튼 추가: 🏆 트로피, 🧪 연구(종합병원부터), 🏗️ 신관(대학병원부터). 🤝 나눔 박스(종합병원부터).
  버튼이 늘어 좁은 화면에서 줄바꿈되는 것은 허용. 모달은 이미 스크롤 가능하므로 길이 증가 허용.
- 상점 탭: 진료과 · 방·설비 · ⚙️ 장비 · 인테리어 · 직원.
- 결산 추가 줄: 🏥 신관 수입 · 🏥 신관 운영비 · 🤝 기부 · 🧪 연구비 · 🏗️ 공사비 · 🏆 트로피 보너스(포함) · 봉사 진료 평판.
- 안내서(📖)와 README에 새 기능 한 줄씩.
- 새 기능이 처음 열릴 때 코코 실장 토스트 한 번씩 ("이제 연구를 할 수 있어요!" 등).

## 빈틈 메우기 (셀프 빌더 점검에서 나온 것)
- 아이 환자의 🧸는 어느 진료과 증상도 아니다 → `symDept`/`validRooms`/증상표/복합 증상·원인 불명 대상에서 빼고, 진료과로 보내면 "소아과로 가야 해요" 말풍선 (벌점 없음).
- 하루 마감: 영업 종료 후 남은 환자를 다 처리해야 끝나는 기존 규칙에 신관 환자도 포함. 단 💎 특실 환자는 입원실처럼 결산 때 퇴원 처리.
- 응급실 구급차 환자는 입구에 잠깐 나타났다가 바로 신관으로 걸어간다(접수 생략).
- 튜토리얼(1일차)과 기존 테스트 동작은 바뀌지 않아야 한다.
- 장비·연구 효과는 모두 하나의 계산 지점(예: `treatDur`, `svcDur`, `navInt`, `pay`)에 곱으로 들어가게 해 중복 적용을 막는다.

## 빌더에게 맡기는 것
- 신관 카드의 정확한 그리드 위치와 내부 칸 배치, 진행 막대 모양.
- 새 환자 스폰 비율·처리 시간 미세 조정 (위 수치는 출발점). 단, 신관 칸 하나 완공 시 하루 수입이 **눈에 띄게(대략 +8~15%)** 늘어야 한다.
- 함수 구조, 테스트 분할(새 파일 `tests/test_endgame.py` 권장).
- 테스트 빌드(`mallang-test.html`, 15일차 대학병원 다 해금 + 돈 많음)를 새 기능 확인용으로 갱신: 신관 1단계 완공 상태, 연구 1개 진행 중 정도.

## 내가 정한 것 (사용자 확인 대상)
- 해금 시점 표, 모든 가격·기간·효과 수치.
- 신관 안에서는 환자 스프라이트 대신 진행 막대 + 대기 인원으로 표시.
